# tongyun-git

一个独立的桌面 Git 图形客户端，对标 IntelliJ IDEA 自带的 Git 面板，目标是更顺手，并且自带 AI。

技术栈：Tauri 2 + Rust（git2 + 系统 git）+ React + TypeScript。

> 当前阶段：**只有规划文档，还没有代码。** 仓库为私有，许可证在决定公开时再定。

## MVP 范围

打开仓库 · 改动列表和 diff · 按文件 / 按 hunk / 按行暂存 · 提交 · 切换和新建分支 · 提交树图 · 拉取和推送 · AI 写提交信息
