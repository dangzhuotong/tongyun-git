## S3 diff 行选择（R-05、R-16）

```
│ [暂存所选 ␣]  已选 2 行                                                     │
│  40 40   function save(u) {                                                 │
│▌ 41    -   return db.put(u)          ← 选中（蓝色背景 + 左侧强调条）         │
│     41 +   validate(u)                                                      │
│▌    42 +   return db.put(u)          ← 选中                                  │
│  42 43   }                                                                  │
```

- 点行号区选中一行，Shift+点扩选；键盘 ↑↓ 移动、Shift+↑↓ 扩选、`a` 选整个 hunk、空格执行。
- 暂存后：被暂存的行从这里消失（淡出 120ms），提示条显示「已暂存 2 行」。要撤回就切到已暂存 diff 选中这些行取消暂存（R-05）。
- 二进制或换行符整体变化的文件：工具条显示「此文件只能整体暂存」，行选择不可用。

## S5 分支弹窗（R-08、R-09）

```
        ┌────────────────────────────────────────┐
        │ 过滤分支…                    [+ 新建分支]│
        │ 本地                                     │
        │ ✓ main              ↑2 ↓0               │
        │   feature/anim      ↑0 ↓3   origin/…    │
        │ 远程                                     │
        │   origin/main                            │
        │   origin/feature/login   （本地无）      │
        └────────────────────────────────────────┘
```

新建分支：

```
        ┌────────────────────────────────────────┐
        │ 新建分支   起点：HEAD (4b8fd47)          │
        │ 名称 [feature/login              ]       │
        │ ☑ 创建后切换                             │
        │                     [取消]  [创建]       │
        └────────────────────────────────────────┘
```

名称不合法时输入框下方显示原因（例如「不能包含 ..」），创建按钮不可用。

切换被阻止：

```
        │ 无法切换到 feature/anim：下列文件的改动会被覆盖 │
        │   src/api/user.ts                             │
        │ 请先提交这些改动。                   [知道了]  │
```

## S6 推送确认（R-12）

```
        ┌────────────────────────────────────────────┐
        │ 推送 main → origin/main                    │
        │ 2 个提交：                                 │
        │   4b8fd47 feat: 素材来源规则               │
        │   86f506e fix: 部署脚本                    │
        │                       [取消]  [推送 ⏎]     │
        └────────────────────────────────────────────┘
```

无上游时标题为「推送 feature/login → origin/feature/login（新建远程分支）」，远程名可下拉选择。被拒绝时对话框内显示「远程有新提交，请先拉取」和「拉取」按钮。
