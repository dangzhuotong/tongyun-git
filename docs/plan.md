# MVP 开发计划与工期

状态：MVP（M0–M6）核心功能已全部开发完成并验证通过（2026-10-08）。全量集成测试、前端测试及 Windows 本地单文件打包均已通过。需求见 [PRD](prd.md)，测试见 [验收测试](testing/acceptance-tests.md)。

## 估算依据

- 节奏：代码由 agent（Antigravity 写小块、Cursor 云端做跨模块和审查）完成，阿码审，阿橦做最终验收。单位是「工作日」，指这种节奏下的日历工作日，不是一个人纯手写的工时。
- 参照：tongyun-planner（同样是 Tauri 2 + React + TS）的工程配置、CI 和打包流程可以直接复用，省掉脚手架和发版摸索的时间。
- 不确定性最大的四块：按行暂存的边界情况（CRLF、新文件、末尾无换行）、提交树图的布局和大仓库性能、Windows 下 git 命令行的编码和路径（中文路径、`core.quotepath`、长路径）、丢弃快照的写入和撤销（暂存区和工作区两份内容都要还原）。
